# Prime Capital Investor Portal — backend dependencies
#
# This set has been verified to resolve with no conflicts. Two notes on why
# certain pins exist, so they are not "tidied up" later and broken again:
#
#   gotrue==2.12.4   pinned deliberately. It is a sub-package of supabase, and
#                    pip will otherwise pull the newest gotrue (2.20.x), which
#                    demands pydantic>=2.11 and conflicts with everything else.
#                    2.12.4 is the version that actually pairs with supabase
#                    2.5.0. Removing this pin reintroduces the conflict.
#
#   httpx[http2]     the [http2] extra is required by gotrue. Plain httpx at
#                    the same version fails resolution.
#
# pandas was removed: nothing in the codebase imports it, and it is a large
# dependency that slows the container build and adds its own constraints.
# ─────────────────────────────────────────────────────────────────────────────

# sync driver for migrations.
#

# distribution". That is a local wheel availability issue only. It installs
